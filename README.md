# 코일센터 경영 시뮬레이터 (베타)

해외 코일센터 사장으로 2026년 1월부터 48개월을 운영하는 경영 시뮬레이션입니다.
주재원과 본사 수출영업 담당자 교육용으로 만들고 있습니다.

## 플레이
- **브라우저에서 바로:** https://savvygonsama.github.io/coil-center-tycoon/
- **내려받아서:** `index.html` 하나만 받아 더블클릭하면 됩니다.
  그림까지 파일 안에 들어 있어 다른 건 필요 없습니다. 설치도 인터넷 연결도 필요 없습니다.

## 시작할 때 고르는 것

**난이도**

| | 노멀 | 하드 |
|---|---|---|
| 자본금 | $65M | $55M |
| 물려받은 판매 기반 | 10.0% | 8.2% |
| 은행 한도 | 자본의 60% | 55% |
| 본사 이익 목표 | $45M | $58M |

하드는 첫 1년을 버티는 것부터 일입니다. 목표가 올라가 S등급은 거의 안 나옵니다.

**결재 주기**

| | 노멀 | 속성 |
|---|---|---|
| 기간 | 48개월 | 16분기 |
| 결재 | 48번 | 16번 |
| 한 번 결재하면 | 한 달 | 석 달 |

속성은 카드 한 벌로 석 달을 돌립니다. 소재 발주 방침·슬리팅 배분·잔업은 석 달 내내
유지되고, 증설·본사 지시 수용·고객군 영업은 분기 첫 달에만 집행됩니다.

## 매 턴 하는 일
공장 화면에서는 아무것도 결정하지 않습니다. 상황만 보고, 직원을 부릅니다.

1. 공장 화면에서 지금 상태를 봅니다
2. **직원들 들어오라고 하기** — 한 명씩 들어와 상황을 보고합니다
3. 고르면 그 자리에서 결과가 나옵니다. 선택지마다 뭘 얻고 잃는지 미리 붙어 있습니다
4. 마지막 결재가 끝나면 그대로 한 달(속성은 석 달)이 갑니다
5. 결산과 경영지표(당월·누계·전월 대비)를 확인합니다

한 턴에 3~5장이 올라옵니다. 소재 발주는 매달 반드시 묻고, 증설·본사 지시·슬리팅 배분은
필요한 달에만 올라옵니다. 같은 주제를 한 턴에 두 번 묻지 않습니다.

## 공장 화면

화면을 셋으로 나눠 봅니다.

- **위 — 부지 전경** : 공장동이 몇 동인지. 증축하면 한 동이 더 섭니다.
- **왼쪽 — 공장 내부 설비** : 라인 하나가 칸 하나. 그 달에 투입이 있으면 가동 컷,
  없으면 정지 컷(회색)으로 바뀌고 가동률이 같이 붙습니다. 설치 중인 라인과 빈 자리도 보입니다.
- **오른쪽 — 야드 재고** : 소재는 톤수에 따라 소·중·대·한도 초과 네 단계로 그림이 바뀝니다.
  3개월 넘은 재고는 파란 방수포를 덮어 빨갛게 표시하고, 미착 물량은 배로 보여줍니다.

그림은 전부 256px 픽셀 아트입니다. 확대해도 뭉개지지 않게 pixelated로 그립니다.

## 베타 테스트에서 듣고 싶은 것
- 카드 문구와 선택지가 실무처럼 들리는지
- 숫자(마진, 리드타임, 비용 규모)가 현실과 다른 곳
- 어디서 "뭘 하고 있는지 모르겠다"고 느꼈는지
- 최종 등급과 몇 년 몇 월에 끝났는지

## 구조
| 파일 | 역할 |
|---|---|
| `engine.js` | 경제 엔진 (재고·수율·현금흐름·고객군·시나리오) |
| `decks.js` | 결재 카드 덱 |
| `ui.js` | 화면 |
| `shell.html` | 스타일 |
| `art/` | 픽셀 스프라이트 21장 + 인물 초상 6장 (256px, 합쳐서 448KB) |
| `assets.js` | 그 27장을 data URI로 박아둔 것. `make-assets.ps1`이 `art/`에서 만듭니다 |
| `build.sh` | 위 파일들을 `index.html` 하나로 묶기 |
| `art-prompts.md` | 27장을 만든 이미지 생성 프롬프트 |

그림이 `index.html` 안에 들어가 있어 배포할 게 파일 하나뿐입니다.
`art/` 폴더의 그림을 바꿨으면 `make-assets.ps1`을 돌린 뒤 `build.sh`를 다시 실행하면 됩니다.
