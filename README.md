# 코일센터 경영 시뮬레이터 (베타)

해외 코일센터 사장으로 2026년 1월부터 48개월을 운영하는 경영 시뮬레이션입니다.
주재원과 본사 수출영업 담당자 교육용으로 만들고 있습니다.

## 플레이
- **브라우저에서 바로:** https://savvygonsama.github.io/coil-center-tycoon/
- **내려받아서:** `index.html` 하나만 받아 더블클릭하면 됩니다.
  그림까지 파일 안에 들어 있어 다른 건 필요 없습니다. 설치도 인터넷 연결도 필요 없습니다.

## 시작할 때 고르는 것

**난이도**

| | 노멀 | 하드 |
|---|---|---|
| 자본금 | $78M | $66M |
| 물려받은 판매 기반 | 10.0% | 8.2% |
| 은행 한도 | 자본의 60% | 55% |
| 본사 이익 목표 | $45M | $58M |

하드는 첫 1년을 버티는 것부터 일입니다. 목표가 올라가 S등급은 거의 안 나옵니다.

**결재 주기**

| | 노멀 | 속성 |
|---|---|---|
| 기간 | 48개월 | 16분기 |
| 결재 | 48번 | 16번 |
| 한 번 결재하면 | 한 달 | 석 달 |

속성은 카드 한 벌로 석 달을 돌립니다. 소재 발주 방침·슬리팅 배분·잔업은 석 달 내내
유지되고, 증설·본사 지시 수용·고객군 영업은 분기 첫 달에만 집행됩니다.

## 부임 — 돌고 있던 회사를 넘겨받는다
2026년 1월, 이미 운영 중인 코일센터에 사장으로 부임합니다. 게임을 시작하면 전임 사장이
굴린 16개월을 엔진이 실제로 돌리고, 그 마지막 12개월을 **작년 실적**으로 넘겨줍니다.
그래서 첫 달부터 창고에 소재와 가공제품이 있고, 바다 위와 본사 공장에 물량이 있고,
받을 돈과 은행 빚이 있습니다.

첫 화면에서 관리부장이 작년 실적을 브리핑하고, 실적표는 **지난달 · 작년 월평균 · 작년 연간**을
보여줍니다. 두 번째 달부터는 **당월 · 부임 후 누계 · 전월 대비**입니다.

실적표에 들어가는 것:

| 구분 | 항목 |
|---|---|
| 판매 | 판매량 (통코일 / 슬리팅 / 레벨링 / 블랭킹), 가공 판매 비중 |
| 고객군별 | J사·E사·C사·P사·H사 판매량과 비중 |
| 손익 (천달러) | 매출액, 영업이익, 순이익, 톤당 영업이익 |
| 설비 | 설비별 가동률 |
| 재고·재원 | 창고 현물(가공제품 따로), 해상 미착, 본사 생산 중, 재고량·**재고율**, 재원량·**재원율**, 장기재고 |
| 자금 (천달러) | 현금, 매출채권, 지연채권, 차입금, 순운전자본 |

- **재고량** = 창고 현물 + 해상 미착, **재고율** = 재고량 ÷ 향후 3개월 내시 평균
- **재원량** = 재고량 + 본사 생산 중, **재원율** = 재원량 ÷ 향후 3개월 내시 평균
- 표준 방침에서 재고율은 2~2.5개월, 재원율은 5개월 남짓입니다 (자동차강판은 제조 3개월 + 해송 1개월)

가공제품은 열흘치쯤 안전재고로 들고 갑니다. 고객 라인은 JIT로 돌고 우리 라인이 매일 그 순서대로 돌 수는 없으니까요.

## 사람들
| | 맡은 일 |
|---|---|
| 정 부장 · 영업 | 고객 영업과 **소재 발주**. 내시를 보고 본사에 소재를 건다 |
| 서 대리 · 구매 | 비품·포장재·**MRO 자재**. 예비품이 없으면 고장 때 더 오래 서고, 포장재가 싸구려면 클레임이 온다 |
| 구 공장장 · 생산 | 라인, 정비, 현장 |
| 한 부장 · 관리 | 재무에 **인사·총무**까지. 임금협상, 성과급, 근로감독, 보험, 세무조사, 사택, 채용 |
| 오 과장 · 품질 | 품질 추세, 클레임 |
| 린 매니저 · 현지 | 현지 직원, 분위기 |

## 매 턴 하는 일
1. **공장 화면에서 보고를 읽습니다.** 지난달 경영현황, 돌아온 청구서, 지난 결재의 영향, 경고,
   부서 보고가 올라와 있습니다. 여기서는 아무것도 결정하지 않습니다.
2. **결재 시작** — 그 달의 안건이 한 건씩 올라옵니다. 선택지마다 뭘 얻고 잃는지 미리 붙어 있습니다.
3. 마지막 결재가 끝나면 그대로 한 달(속성은 석 달)이 갑니다.

## 이 게임의 약속 — 과거의 결정이 미래의 문제를 만든다

**안건은 고정된 카드 더미에서 뽑지 않습니다.** 회사 상태와 지난 결정들이 그 달의 안건을 만듭니다.
정비를 미뤘으면 고장이, 가격을 깎아줬으면 또 깎아달라는 요구가, 재고를 쌓았으면 현금난이 올라옵니다.
조용한 달에는 안건이 한두 건이고, 사고가 겹친 달에는 네 건입니다. 같은 주제는 한 달에 한 번만 묻습니다.

**플레이어에게 보이지 않는 숫자가 있습니다.** 설비 상태, 품질, 현장 피로, 고객사별 관계와 양보 기억,
경쟁사 공격성, 본사 가격 방향. 이 값들은 매달 서로를 움직입니다.

```
물량을 받는다 → 가동률 ↑ → 설비가 닳고 현장이 지친다 → 품질 ↓ → 클레임
→ 그 고객 관계 ↓ → 경쟁사가 파고든다 → 물량이 빠진다
```

플레이어는 이 숫자를 직접 보지 못하고 **부장들의 보고**로 짐작합니다. 보고에는
**확인·추정·소문**이 섞여 있고, 소문은 틀릴 수 있습니다.

**사건이 터질 때는 원인을 짚습니다.** 게임은 모든 결정을 기억합니다.

> 1호 라인이 섰습니다. 두 달 전 정비 연기 이후로 무리하게 돌렸습니다. 최근 넉 달 중 4달을 가동률 90% 넘게 돌렸습니다.

> 납기를 못 맞췄습니다. J사와 P사가 불만을 표시했습니다. 원인 · 석 달 전 하락 소문에 발주 축소

**결재 다음 달에는 그 결정이 무엇을 움직였는지 보여줍니다.**

> J사 대량 수주 — 판매량 +1,200t · 가동률 +4%p · J사 단가 −$12/t · 월 이익 −$45k · ⚠ 2~4개월 뒤 설비·품질 부담

## 4년의 흐름
| | 테마 | 무슨 일이 |
|---|---|---|
| 1년차 | 정상화 | 영업으론 겨우 남고 이자 내면 적자인 회사, 미뤄둔 정비, 묵은 일반재 2,400톤 |
| 2년차 | 성장 | 본사가 소재 판매 15% 증가를 요구, 물량 제안 |
| 3년차 | 성장의 부작용 | 작년에 늘린 것들의 청구서 |
| 4년차 | 위기와 선택 | 지금까지의 선택이 결과로 |

매년 1월에 본사가 연간 소재 목표를 내려보냅니다. 재무는 현금을, 생산은 캐파를, 영업은 가격을
걱정합니다. 받을지, 절충할지, 낮출지는 사장이 정하고, 연말에 그 약속으로 평가받습니다.

## 정답 스타일은 없습니다
스타일별로 다섯 판씩 자동 플레이한 결과입니다 (노멀, 부임 인수 시작).

| 한쪽으로만 간 경영 | 완주 | 본사 이익 | 치른 대가 |
|---|---|---|---|
| 공격적 성장 (전부 수락·정비 전부 연기) | 1/5 | $30.1M | 고장 6번, 운전자금 폭증 |
| 안정적 수익 | 5/5 | $11.2M | 결품 27번, 점유율 10% → 2% |
| 생산효율 | 5/5 | $41.8M | 결품 10번 |
| 고객관계 | 5/5 | $23.8M | 고장 5번, 양보 누적 |
| 상황 따라 섞기 | 5/5 | $31.2M | — |

끝나면 점수 대신 **"당신이 만든 회사"**를 서술로 보여줍니다. 어떤 스타일이었는지, 그래서 무엇을
얻고 무엇을 치렀는지, 다음 판에는 무엇을 반대로 해보면 좋을지.

## 공장 화면

보고 아래에 공장 그림이 있습니다.

- **왼쪽 — 공장동** : 증축하면 같은 동이 하나 더 섭니다.
- **오른쪽 — 설비** : 라인 하나가 한 줄. 이번 달 주문이 있으면 가동 컷, 없으면 회색 정지 컷.
  설치 중인 라인과 빈 자리도 같은 줄로 보입니다.
- **아래 — 야드** : 소재는 톤수에 따라 소·중·대·한도 초과로 그림이 바뀝니다.
  3개월 넘은 재고는 파란 방수포를 덮고 빨갛게, 미착 물량은 배로 보입니다.

그림은 전부 256px 픽셀 아트입니다. 확대해도 뭉개지지 않게 pixelated로 그립니다.

## 베타 테스트에서 듣고 싶은 것
- 카드 문구와 선택지가 실무처럼 들리는지
- 숫자(마진, 리드타임, 비용 규모)가 현실과 다른 곳
- 어디서 "뭘 하고 있는지 모르겠다"고 느꼈는지
- 최종 등급과 몇 년 몇 월에 끝났는지

## 구조
| 파일 | 역할 |
|---|---|
| `engine.js` | 경제 엔진 (재고·수율·현금흐름·고객군·시나리오) |
| `world.js` | 숨은 변수(설비·품질·관계·피로)와 인과, 기억, 부서 보고, 경고, 최종 평가 |
| `issues.js` | 회사 상태에서 그 달의 안건을 만든다 |
| `decks.js` | 외부 충격과 사내 이야기 카드 |
| `ui.js` | 화면 |
| `shell.html` | 스타일 |
| `art/` | 픽셀 스프라이트 20장 + 인물 초상 6장. 여백을 잘라낸 원본 |
| `assets.js` | 그 26장을 data URI로 박아둔 것. `make-assets.ps1`이 `art/`에서 만듭니다 |
| `build.sh` | 위 파일들을 `index.html` 하나로 묶기 |
| `art-prompts.md` | 이미지 생성 프롬프트 |

그림이 `index.html` 안에 들어가 있어 배포할 게 파일 하나뿐입니다.
`art/` 폴더의 그림을 바꿨으면 `make-assets.ps1`을 돌린 뒤 `build.sh`를 다시 실행하면 됩니다.
