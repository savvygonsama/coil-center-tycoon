# 코일센터 경영 시뮬레이터 (베타)

해외 코일센터 사장으로 2026년 1월부터 48개월을 운영하는 경영 시뮬레이션입니다.
주재원과 본사 수출영업 담당자 교육용으로 만들고 있습니다.

## 플레이
- **브라우저에서 바로:** https://savvygonsama.github.io/coil-center-tycoon/
- **내려받아서:** `coil-center-beta.zip`을 풀고 `index.html`을 더블클릭합니다.
  `index.html`과 `art/` 폴더가 **같은 자리에 함께 있어야** 공장 그림이 뜹니다.
  설치나 인터넷 연결은 필요 없습니다.

## 시작할 때 고르는 것
| | 노멀 | 속성 |
|---|---|---|
| 기간 | 48개월 | 16분기 |
| 결재 | 48번 | 16번 |
| 한 번 결재하면 | 한 달 | 석 달 |

속성은 카드 한 벌로 석 달을 돌립니다. 소재 발주 방침·슬리팅 배분·잔업은 석 달 내내
유지되고, 증설·본사 지시 수용·고객군 영업은 분기 첫 달에만 집행됩니다.

## 매 턴 하는 일
1. 결재 카드가 한 장씩 올라옵니다 — 구매 / 영업·고객 개척 / 생산, 가끔 주요 사건
2. 고르면 바로 결과가 나옵니다
3. 공장 화면에서 슬리팅 배분, 소재 발주 여유를 정하고 결재합니다
4. 결산과 경영지표(당월·누계·전월 대비)를 확인합니다

## 공장 그림
`art/base.jpg` 위에 공장동·설비·재고·차량을 레이어로 얹어 그립니다.
경영 상태가 그대로 그림에 나옵니다.

- 증설하면 공장동이 두 동이 됩니다
- 라인이 놀면 설비가 정지 컷으로 바뀝니다
- 재고가 늘면 야드에 코일이 쌓이고, 한도를 넘기면 통로까지 넘칩니다
- 석 달 넘은 재고는 파란 방수포를 덮어 구석에 세워둡니다
- 미착 물량이 있으면 배가 떠 있습니다

스프라이트 위치는 `ui.js`의 `plantView()`에 컨테이너 대비 %로 적혀 있습니다.
기준점은 밑변 가운데, 즉 물건이 바닥에 닿는 지점입니다.

## 베타 테스트에서 듣고 싶은 것
- 카드 문구와 선택지가 실무처럼 들리는지
- 숫자(마진, 리드타임, 비용 규모)가 현실과 다른 곳
- 어디서 "뭘 하고 있는지 모르겠다"고 느꼈는지
- 최종 등급과 몇 년 몇 월에 끝났는지

## 구조
| 파일 | 역할 |
|---|---|
| `engine.js` | 경제 엔진 (재고·수율·현금흐름·고객군·시나리오) |
| `decks.js` | 결재 카드 덱 |
| `ui.js` | 화면 |
| `shell.html` | 스타일 |
| `build.sh` | 네 파일을 `index.html` 하나로 묶기 |
| `art/` | 공장 전경 스프라이트 21장 + 인물 초상 6장 |
| `art-prompts.md` | 그 27장을 만든 이미지 생성 프롬프트 |

원본 이미지(1254px, 46MB)는 `art-src/`에 있고 저장소에는 올리지 않습니다.
`art/`는 투명 여백을 잘라내고 표시 크기에 맞춰 줄인 배포본입니다.
